# Carrusel Del Home

Coloca aquí solo las imágenes que deben aparecer en el hero/carrusel del home.

No uses esta carpeta para portadas de artículos, aniversarios o galerías de posts.

Reglas:

- Formatos recomendados: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`
- Se cargan automáticamente
- Se muestran en orden alfabético del archivo

Ejemplo:

- `01-salida-nocturna.jpg`
- `02-ruta-dominguera.jpg`
- `03-convivencia.webp`
