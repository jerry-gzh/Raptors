# Public Posts

Aquí van los archivos públicos asociados a eventos o publicaciones específicas.

Ejemplos:

- imágenes públicas embebidas desde Markdown
- descargas `.gpx`
- HTML auxiliares como timers o mapas

Organización recomendada:

- `public/posts/aniversario25/`
- `public/posts/aniversario26/`

Mantén cada evento dentro de su propia carpeta.
